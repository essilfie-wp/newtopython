How to Host This Python Web App on Netlify

Netlify serves this entire web application seamlessly. Because PyScript runs Python in the browser with WebAssembly, no expensive backend servers or complicated Docker containers are needed!

Fastest (10 seconds)

Method 1: Drag & Drop to Netlify Drop

No Git commands or terminal required. Deploy instantly from your Windows folder:

  1. Open app.netlify.com/drop in your web browser.
  2. Sign in or create a free Netlify account.
  3. Open File Explorer and navigate to this workspace:
    d:\GIT\newtopython
  4. Drag the entire folder and drop it into the designated upload area on the Netlify webpage.
  5. Your Python web application is live instantly with an HTTPS .netlify.app URL! 🎉
Recommended

Method 2: Automatic Git Deployment

Automatically redeploys every time you push code to GitHub:

  1. Push your project to GitHub:
    git add .
    git commit -m "Add Python web application"
    git push origin main
  2. Go to app.netlify.com and click Add new site → Import an existing project.
  3. Select your GitHub repository.
  4. Configure build settings:
    • Build command: Leave empty (or echo done)
    • Publish directory: . (root)
  5. Click Deploy Site. Your site is continuously deployed!
CLI Option

Method 3: Deploy via Netlify CLI

Deploy directly from PowerShell without leaving your terminal:

# Deploy to a live production URL
npx netlify deploy --prod --dir=.

💻 How to Test Locally

We created a custom Python server script (server.py). To test this web application right now on your machine:

py server.py

Then open http://localhost:8080 in your web browser.
